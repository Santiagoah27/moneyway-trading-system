# Roadmap

Fases provisionales:

1. Repository bootstrap.
2. Strategy documentation.
3. Architecture and stack decisions.
4. Domain and deterministic rule engine.
5. Assisted analysis.
6. Historical replay.
7. Backtesting.
8. Shadow mode.
9. Paper trading.
10. Supervised demo execution.
11. Failure diagnosis.
12. Candidate strategy evaluation.

El avance entre fases depende del cumplimiento de pruebas y criterios de aceptación, no solamente de haber escrito código. Todavía no se asignan fechas estimadas.
