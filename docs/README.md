# Documentation

Este directorio es el índice de la documentación del sistema:

- `architecture/` contiene el diseño vigente.
- `decisions/` contiene los Architecture Decision Records (ADRs).
- `roadmap/` contiene las fases y sus entregables.
- `strategies/` contiene las especificaciones auditadas de las estrategias.

Las reglas Forex y Nasdaq deben permanecer separadas. Ninguna regla `unresolved` puede implementarse como condición automática.
