# Strategies

- MoneyWay Forex y MoneyWay Nasdaq son estrategias independientes y deben mantenerse separadas.
- Cada estrategia tendrá versiones auditadas.
- Cada regla debe incluir su estado de evidencia.
- Las reglas subjetivas o `unresolved` requieren validación humana.
- Los documentos de estrategia no deben contener secretos ni credenciales.
- Las modificaciones futuras deberán crear nuevas versiones.
